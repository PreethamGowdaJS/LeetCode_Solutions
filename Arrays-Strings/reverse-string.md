## Problem: Reverse a String (Easy)

**Link:** https://leetcode.com/problems/reverse-string/

### Approach

I used two pointers, one starting from the beginning of the string and
the other from the end. The characters at these positions are swapped
until the two pointers meet.

### Complexity

- Time: O(n)
- Space: O(1)

### Notes

I tested the solution using a normal string and a single-character
string to check the edge case.
